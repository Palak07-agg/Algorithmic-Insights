# Algorithmic-Insights
Sorting Algorithm Visualizer is a web-based tool that visually demonstrates how different sorting algorithms work. Users can interact with the tool to generate arrays of different sizes, adjust sorting speeds, and view the time taken by each algorithm.

Features
Sorting Algorithms:
1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Quick Sort
5. Merge Sort

Interactive Controls:
1. Adjust array size using a slider.
2. Control the sorting speed dynamically.
3. Regenerate random arrays with a button.

Performance Measurement:
- Displays the time taken by each sorting algorithm.
Responsive Design:
- Works seamlessly across various screen sizes and devices.

Technologies Used
- HTML: Structure of the webpage.
- CSS: Styling and animations for the array visualization.
- JavaScript: Logic for sorting algorithms and dynamic interactions.
  
Getting Started
Follow these steps to run the project locally:

Prerequisites
- A web browser (e.g., Chrome, Firefox, Edge).
Installation
- Clone the repository:
git clone https://github.com/your-username/sorting-visualizer.git
- Navigate to the project directory:
cd sorting-visualizer
- Open index.html in your web browser.

How to Use
- Generate Array:
Click the Generate Array button to create a random array.
- Adjust Array Size:
Use the slider to change the size of the array.
- Adjust Speed:
Use the speed control slider to slow down or speed up the sorting visualization.
- Choose a Sorting Algorithm:
Click on a sorting algorithm button (e.g., Bubble Sort) to visualize the sorting process.
- View Time Taken:
The time taken by the algorithm is displayed after completion.
